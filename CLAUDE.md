# VR Modding Playbook

The routing rules for this repository live in **[AGENTS.md](AGENTS.md)** — read that first.

It is kept in one file rather than two so the two hosts cannot drift apart. Everything that
would go here is there: how to route by symptom, recipe or blocker instead of reading chapters;
the pattern and `FAIL-` ID namespaces; evidence grading; and how to validate a change.

For substantial findings, use [research receipts](docs/research-receipts.md): record
project-owned evidence, validate it, and submit a candidate for review. Read the
canonical workflow for commands and proof boundaries; intake never promotes claims.

**The one rule, if you read nothing else:** use the retrieval layer to reach one relevant
section, not whole chapters. Current corpus measurements live in
[coverage](docs/coverage.md). Route; do not read end to end.
